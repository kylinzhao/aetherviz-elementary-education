1. 高对比度模式

提供最大可读性的配色方案，对比度超过 WCAG AAA 标准。

快捷键: Alt + H

2. 文字大小调节

在 100%-200% 范围内调节文字大小，布局不会被破坏。

快捷键: Alt + + / Alt + -

这段文字会随设置变化。当前大小: 100%

3. 减少动画

为前庭障碍用户提供的选项，禁用所有非必要动画。

快捷键: Alt + R

呼吸动画示例（减少动画时会停止）

4. 键盘导航

所有功能都可以仅使用键盘完成。

  • Tab - 下一个元素
  • Shift + Tab - 上一个元素
  • Enter / Space - 激活按钮
  • Escape - 关闭面板
  • 方向键 - 调节滑块
