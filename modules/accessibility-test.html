1. 键盘导航测试

Tab 键导航 ✓

使用 Tab 键在所有可交互元素之间导航。焦点应该清晰可见。

Enter/Space 激活 ✓

方向键调节滑块 ✓

2. 高对比度模式测试

对比度检查 ✓

检查文字与背景的对比度是否达到 WCAG AA 标准 (4.5:1)。

黑底白字 - 对比度 21:1 (AAA)
白底黑字 - 对比度 21:1 (AAA)
黑底黄字 - 对比度 19:1 (AAA)

焦点可见性 ✓

高对比度模式下，焦点指示器应该非常明显。
