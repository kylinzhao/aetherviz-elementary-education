🎓 教学系统演示
❓ 问答互动系统
一个通用的问答系统模块，支持选择题、判断题等多种题型，提供即时反馈和连胜记录。
📝 多种题型
支持选择题、判断题、填空题
⚡ 即时反馈
正确/错误的动画反馈
🔥 连胜记录
追踪连续答对题数
🎉 表扬效果
3题以上触发庆祝动画
使用示例： window.quizSystem = new QuizSystem({ lessonId: 'lesson-square', container: document.getElementById('quiz-container'), onAnswer: (result) => { console.log('答题结果:', result); } });
📋 探索式学习任务系统
任务引导系统，帮助学生通过探索式学习掌握知识，提供渐进式提示和完成检测。
🎯 任务目标
清晰的任务目标说明
💡 渐进提示
3级提示从简单到详细
⏰ 智能触发
1分钟无进展自动提示
✅ 完成祝贺
任务完成庆祝动画
使用示例： window.taskSystem = new TaskSystem({ lessonId: 'lesson-square', container: document.getElementById('task-container'), onTaskComplete: () => { console.log('任务完成！'); } });
