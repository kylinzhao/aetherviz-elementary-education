# 学习进度追踪系统规范

## 新增需求

### 需求:任务完成追踪
系统必须永久追踪每个课程的任务完成状态。

#### 场景:初始状态
- **当** 用户首次进入课程
- **那么** 所有任务显示为未完成状态（⬜）
- **并且** 进度条显示 0%

#### 场景:任务完成检测
- **当** 用户调整参数满足任务条件
- **那么** 系统自动检测任务完成
- **并且** 将任务状态更新为已完成（✅）
- **并且** 任务标题显示删除线效果
- **并且** 显示任务提示信息

#### 场景:永久保存
- **当** 任务标记为已完成
- **那么** 系统永久保存完成状态
- **禁止** 参数调整导致任务状态回退
- **即使** 用户刷新页面，完成状态必须保持

#### 场景:进度更新
- **当** 任务完成状态变化
- **那么** 进度条自动更新
- **并且** 显示新的完成数（X/Y）
- **并且** 进度条平滑过渡到新位置

### 需求:测验得分追踪
系统必须追踪测验答题情况并计算总分。

#### 场景:答题记录
- **当** 用户回答问题
- **那么** 系统记录题目 ID 和答案
- **并且** 防止重复计分

#### 场景:得分计算
- **当** 用户回答正确
- **那么** 系统增加得分
- **当** 用户回答错误
- **那么** 系统不增加得分
- **并且** 得分上限为 5 分

#### 场景:得分显示
- **当** 用户完成所有题目
- **那么** 系统显示总分（X/5）
- **并且** 显示星级评分（⭐ × 得分）
- **并且** 星级数量等于得分

### 需求:全部完成检测
系统必须检测用户是否完成所有学习目标。

#### 场景:完成条件
- **当** 所有任务已完成
- **并且** 测验得分 ≥ 4/5
- **那么** 系统判定学习完成

#### 场景:未完成状态
- **当** 任务未全部完成或测验得分 < 4/5
- **那么** 系统不显示完成庆祝
- **并且** 鼓励用户继续学习

### 需求:进度可视化反馈
系统必须提供清晰的视觉反馈，帮助儿童理解进度。

#### 场景:任务状态图标
- **当** 任务未完成且是下一个任务
- **那么** 显示 👉 图标（带跳动动画）
- **当** 任务已完成
- **那么** 显示 ✅ 图标
- **当** 任务未完成且不是下一个
- **那么** 显示 ⬜ 图标（半透明）

#### 场景:进度条颜色
- **当** 显示进度条
- **那么** 使用黄色到橙色渐变
- **并且** 进度条平滑过渡
- **并且** 进度条背景为灰色（半透明）

#### 场景:全部完成提示
- **当** 所有任务完成
- **那么** 显示"🎉 太棒了！所有任务完成！"提示
- **并且** 显示"你真是个小天才！继续加油！"鼓励语
