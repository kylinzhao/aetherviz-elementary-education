# 交互式学习系统规范

## 新增需求

### 需求:任务引导系统
每个课程必须提供渐进式任务引导，帮助小学生逐步理解学习内容。

#### 场景:显示任务列表
- **当** 用户进入课程页面
- **那么** 系统显示 3-5 个渐进式任务
- **并且** 每个任务包含标题、描述和完成状态指示

#### 场景:任务完成检测
- **当** 用户完成任务的指定条件（如调整参数到特定值）
- **那么** 系统自动检测任务完成
- **并且** 标记任务为已完成状态（✅）
- **并且** 显示任务提示信息

#### 场景:永久进度保存
- **当** 用户完成任务后修改参数
- **那么** 已完成的任务保持完成状态
- **禁止** 任务状态回退到未完成

#### 场景:进度可视化
- **当** 用户查看任务列表
- **那么** 系统显示进度条
- **并且** 显示已完成任务数/总任务数

### 需求:测验游戏系统
每个课程必须提供测验游戏，检验学习效果并提供即时反馈。

#### 场景:测验题目展示
- **当** 用户查看测验区域
- **那么** 系统显示 5 道选择题
- **并且** 每题包含 4 个选项
- **并且** 显示当前进度（第 X 题，共 5 题）

#### 场景:答题反馈
- **当** 用户选择答案
- **如果** 答案正确
- **那么** 系统显示 ✅ 标记和正确提示
- **并且** 增加得分
- **如果** 答案错误
- **那么** 系统显示 💡 提示图标和提示信息

#### 场景:提示使用
- **当** 用户答题错误后
- **那么** 系统显示提示（hint）
- **并且** 用户可以再次尝试

#### 场景:详细解释
- **当** 用户查看答案后
- **那么** 系统显示详细解释（explanation）
- **并且** 解释帮助理解正确答案的原因

#### 场景:完成庆祝
- **当** 用户完成所有 5 道题
- **那么** 系统显示总分
- **并且** 显示星级评分（⭐）
- **并且** 如果得分 ≥ 4/5，显示庆祝动画

#### 场景:防止重复计分
- **当** 用户重复回答同一题目
- **那么** 系统不重复计分
- **并且** 保持首次答案的得分

### 需求:学习完成认证
当用户完成所有任务且测验得分达标时，系统必须提供完成认证。

#### 场景:完成条件检查
- **当** 所有任务已完成
- **并且** 测验得分 ≥ 4/5
- **那么** 系统显示完成庆祝弹窗

#### 场景:庆祝弹窗内容
- **当** 显示完成庆祝弹窗
- **那么** 系统显示 🏆 图标
- **并且** 显示"太棒了！"等鼓励文字
- **并且** 显示测验得分和星级
- **并且** 提供"继续探索其他课程"按钮

#### 场景:返回导航
- **当** 用户点击"继续探索其他课程"按钮
- **那么** 系统导航到首页
