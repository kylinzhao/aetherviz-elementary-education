# 提案：儿童友好的课程交互式学习改造

## 为什么

现有的AetherViz小学教学项目虽然有完善的3D可视化演示，但在教学讲解和儿童理解方面存在不足。课程内容过于学术化，缺乏针对小学生的互动引导和游戏化学习体验，难以激发儿童的学习兴趣和理解力。

通过将40个数学和科学课程改造为儿童友好的互动式学习模式，可以显著提升教学效果和学习体验。

## 变更内容

### 新增功能
- **任务卡片系统**：每个课程增加3-5个渐进式引导任务，永久进度跟踪
- **测验游戏组件**：每个课程增加5道测验题，带提示和详细解释
- **故事化引入**：每个课程以儿童友好的故事开始（如"小明的饼干派对"、"披萨派对"）
- **即时反馈机制**：任务完成和测验答题的即时反馈和庆祝动画
- **自动滚动到顶部**：路由切换时自动滚动到页面顶部

### 组件改造
- 创建 `TaskCard.tsx` 可复用组件，支持永久完成追踪
- 创建 `QuizGame.tsx` 可复用组件，支持星级评分
- 改造所有40个课程页面，统一使用新组件

### 修复
- 修复多个TypeScript编译错误（类型断言、属性位置等）
- 创建 `ScrollToTop` 组件解决路由切换滚动问题

## 功能 (Capabilities)

### 新增功能
- `interactive-learning-system`: 交互式学习系统，包含任务引导和测验游戏功能
- `child-friendly-ui`: 儿童友好的用户界面，包括故事引入、emoji图标、游戏化反馈
- `progress-tracking`: 学习进度追踪系统，永久保存任务完成状态

### 修改功能
- `math-lessons`: 19个数学课程从纯演示模式改造为互动学习模式
- `science-lessons`: 21个科学课程从纯演示模式改造为互动学习模式
