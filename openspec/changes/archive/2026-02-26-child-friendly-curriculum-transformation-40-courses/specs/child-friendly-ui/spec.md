# 儿童友好用户界面规范

## 新增需求

### 需求:故事化引入
每个课程必须以儿童友好的故事开始，激发学习兴趣。

#### 场景:故事展示
- **当** 用户进入课程页面
- **那么** 系统显示故事引入区域
- **并且** 故事包含 📖 图标
- **并且** 故事使用儿童角色（如"小明"、"小华"）
- **并且** 故事与课程主题相关

#### 场景:故事内容结构
- **当** 显示故事内容
- **那么** 故事必须包含背景情境
- **并且** 包含学习目标
- **并且** 使用 emoji 和生动的描述
- **并且** 语言简单易懂（适合 6-12 岁儿童）

#### 场景:故事主题示例
- **当** 课程是乘法
- **那么** 故事主题为"小明的饼干派对"
- **当** 课程是分数
- **那么** 故事主题为"披萨派对"
- **当** 课程是除法
- **那么** 故事主题为"生日派对大挑战"

### 需求:游戏化视觉设计
系统必须使用游戏化的视觉设计，吸引儿童注意力。

#### 场景:Emoji 图标使用
- **当** 显示课程标题
- **那么** 标题必须包含相关 emoji 图标
- **并且** emoji 与课程内容相关
- **例如** 🍪 饼干、🍕 披萨、🍰 蛋糕、🦋 蝴蝶

#### 场景:色彩方案
- **当** 设计课程页面
- **那么** 每个课程使用独特的渐变色彩
- **并且** 色彩明亮友好（适合儿童）
- **例如** 蓝色系（数学）、粉色系（科学）、绿色系（自然）

#### 场景:动画反馈
- **当** 用户完成任务
- **那么** 系统显示庆祝动画
- **当** 用户答题正确
- **那么** 系统显示闪光或跳动效果

### 需求:3D 可视化交互
每个课程必须保持 3D 可视化功能，支持儿童探索。

#### 场景:3D 场景展示
- **当** 用户进入课程
- **那么** 系统显示 3D 可视化场景
- **并且** 提供视角控制按钮（重置、顶部、前部、侧面、等轴）
- **并且** 支持鼠标拖动旋转和缩放

#### 场景:控制面板
- **当** 用户查看控制面板
- **那么** 系统显示滑块控件
- **并且** 滑块使用儿童友好的图标（如 🍴 吃掉几块、🔪 切成几块）
- **并且** 实时更新 3D 场景和计算结果

### 需求:信息层级和布局
系统必须使用清晰的布局，帮助儿童理解信息结构。

#### 场景:页面布局
- **当** 显示课程页面
- **那么** 左侧显示 3D 场景和任务
- **并且** 右侧显示控制面板和测验
- **并且** 使用玻璃态（glass-panel）卡片样式

#### 场景:导航栏
- **当** 用户查看任何页面
- **那么** 顶部显示固定导航栏
- **并且** 包含课程标题和 emoji 图标
- **并且** 提供"返回首页"按钮

#### 场景:响应式设计
- **当** 用户在不同设备上访问
- **那么** 布局自动适应屏幕大小
- **并且** 移动端显示单列布局
- **并且** 平板和桌面显示双列布局

### 需求:可访问性
系统必须确保对所有儿童可访问，包括有特殊需求的儿童。

#### 场景:字体大小
- **当** 显示文本内容
- **那么** 标题使用大号字体（text-3xl 或更大）
- **并且** 正文使用易读的字体大小（text-lg 或 text-base）

#### 场景:颜色对比度
- **当** 设计界面
- **那么** 文本与背景对比度满足 WCAG AA 标准
- **并且** 关键信息使用高对比度颜色（如黄色、绿色）
