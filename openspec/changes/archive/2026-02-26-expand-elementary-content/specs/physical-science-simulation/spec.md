# 物理科学模拟规范增量

## 新增需求

### 需求:声学可视化
系统必须提供声音传播、振动、音调等声学概念的可视化教学功能。

#### 场景:声音产生可视化
- **当** 用户打开声音的传播页面
- **那么** 系统必须显示发声物体（如音叉、鼓面）
- **并且** 用户必须能够点击或敲击物体产生声音
- **并且** 物体必须显示振动动画（快速往复运动）
- **并且** 系统必须标注"物体振动产生声音"

#### 场景:声波传播可视化
- **当** 物体开始振动
- **那么** 系统必须显示声波从声源向外传播
- **并且** 声波必须使用同心圆或正弦波表示
- **并且** 声波传播速度必须可调节
- **并且** 系统必须标注"声波需要介质传播"

#### 场景:音调与频率关系
- **当** 用户切换到音调模式
- **那么** 系统必须提供不同频率的声源（如琴弦）
- **并且** 用户必须能够调节振动频率
- **并且** 高频率（高音调）必须显示密集的波形
- **并且** 低频率（低音调）必须显示稀疏的波形
- **并且** 系统必须播放对应音调的声音（可选）

#### 场景:响度与振幅关系
- **当** 用户切换到响度模式
- **那么** 系统必须展示振幅对响度的影响
- **并且** 大振幅（大声）必须显示高的波形
- **并且** 小振幅（小声）必须显示低的波形
- **并且** 用户必须能够调节振幅大小
- **并且** 系统必须标注"振幅越大，响度越大"

#### 场景:声音在不同介质中传播
- **当** 用户切换到介质模式
- **那么** 系统必须展示声音在固体、液体、气体中的传播
- **并且** 用户必须能够选择不同介质
- **并且** 固体中传播速度必须最快
- **并且** 气体中传播速度必须最慢
- **并且** 系统必须标注"真空中不能传声"

### 需求:光学可视化
系统必须提供光的传播、反射、折射等光学概念的可视化教学功能。

#### 场景:光的直线传播
- **当** 用户打开光的传播页面
- **那么** 系统必须显示光源（如太阳、灯泡）
- **并且** 系统必须显示光线沿直线传播的动画
- **并且** 光线必须使用明亮的直线或箭头表示
- **并且** 用户必须能够放置障碍物观察影子形成
- **并且** 系统必须标注"光沿直线传播"

#### 场景:光的反射演示
- **当** 用户切换到反射模式
- **那么** 系统必须显示光源、平面镜和反射光线
- **并且** 用户必须能够调节入射角
- **并且** 系统必须实时计算并显示反射角
- **并且** 反射角必须等于入射角
- **并且** 系统必须标注入射光线、反射光线、法线

#### 场景:光的折射演示
- **当** 用户切换到折射模式
- **那么** 系统必须显示光线从空气进入水中
- **并且** 系统必须显示光线的偏折
- **and** 用户必须能够调节入射角
- **并且** 系统必须标注"光从空气进入水中，折射角小于入射角"
- **并且** 系统必须展示折射和反射同时发生

#### 场景:凸透镜成像
- **当** 用户切换到透镜模式
- **那么** 系统必须显示凸透镜、物体和成像
- **并且** 用户必须能够移动物体位置
- **并且** 系统必须实时显示像的位置和大小
- **并且** 系统必须标注实像和虚像的区别
- **并且** 系统必须展示三种成像情况（放大、缩小、等大）

#### 场景:光的色散
- **当** 用户切换到色散模式
- **那么** 系统必须展示白光通过棱镜分解成七色光
- **并且** 色散过程必须使用彩虹色动画
- **并且** 系统必须标注红橙黄绿青蓝紫七色
- **并且** 系统必须解释彩虹的形成原理

### 需求:电磁学可视化
系统必须提供电路基础、磁铁磁性等电磁学概念的可视化教学功能。

#### 场景:简单电路连接
- **当** 用户打开电路基础页面
- **那么** 系统必须提供电池、灯泡、开关、导线等元件
- **并且** 用户必须能够拖动元件连接电路
- **并且** 电路闭合时灯泡必须发光
- **并且** 电路断开时灯泡必须熄灭
- **并且** 系统必须标注"电流形成闭合回路"

#### 场景:串联电路演示
- **当** 用户切换到串联模式
- **那么** 系统必须提供两个灯泡
- **并且** 用户连接成串联电路
- **那么** 两个灯泡必须同时发光或同时熄灭
- **并且** 一个灯泡损坏另一个必须也熄灭
- **并且** 系统必须显示电流路径只有一条

#### 场景:并联电路演示
- **当** 用户切换到并联模式
- **那么** 系统必须提供两个灯泡
- **并且** 用户连接成并联电路
- **那么** 两个灯泡必须独立控制
- **并且** 一个灯泡损坏另一个必须仍然发光
- **并且** 系统必须显示电流有多条路径

#### 场景:导体与绝缘体
- **当** 用户切换到材料模式
- **那么** 系统必须提供不同材料（铜、铁、塑料、木块）
- **并且** 用户必须能够测试不同材料是否导电
- **并且** 导体必须允许电流通过
- **并且** 绝缘体必须阻止电流通过
- **并且** 系统必须标注材料类型

#### 场景:磁铁的两极
- **当** 用户打开磁铁的磁性页面
- **那么** 系统必须显示条形磁铁或蹄形磁铁
- **并且** 系统必须标注N极（北极）和S极（南极）
- **并且** N极必须使用红色，S极必须使用蓝色
- **并且** 用户必须能够旋转磁铁

#### 场景:磁极间的相互作用
- **当** 用户切换到相互作用模式
- **那么** 系统必须提供两个磁铁
- **并且** 用户必须能够使两个磁铁靠近
- **并且** 同名磁极必须互相排斥（推开）
- **并且** 异名磁极必须互相吸引（拉近）
- **并且** 系统必须使用动画展示排斥和吸引过程

#### 场景:磁场线可视化
- **当** 用户切换到磁场模式
- **那么** 系统必须显示磁铁周围的磁场线
- **并且** 磁场线必须从N极出发回到S极
- **并且** 用户必须能够放置小磁针观察磁场方向
- **并且** 磁场线密集处磁性必须强
- **并且** 磁场线稀疏处磁性必须弱

#### 场景:电磁铁
- **当** 用户切换到电磁铁模式
- **那么** 系统必须显示螺线管和电池
- **并且** 用户必须能够控制电路通断
- **并且** 电路接通时螺线管必须产生磁性
- **并且** 电路断开时磁性必须消失
- **并且** 用户必须能够改变电流方向改变磁极

### 需求:力学扩展可视化
系统必须提供浮力原理等力学概念的可视化教学功能，补充简单机械系列。

#### 场景:浮力现象观察
- **当** 用户打开浮力原理页面
- **那么** 系统必须显示水槽和不同物体（木块、铁块、塑料块）
- **并且** 用户必须能够将物体放入水中
- **并且** 密度小于水的物体必须漂浮
- **并且** 密度大于水的物体必须下沉
- **并且** 系统必须显示物体排开的水

#### 场景:阿基米德原理演示
- **当** 用户切换到原理模式
- **那么** 系统必须显示溢水杯和小桶
- **并且** 物体浸入水中必须排开水到小桶
- **并且** 系统必须对比物体重量和排开水的重量
- **并且** 两者重量必须相等
- **并且** 系统必须标注"浮力等于排开液体的重力"

#### 场景:浮力计算可视化
- **当** 用户切换到计算模式
- **那么** 系统必须显示浮力计算公式 F浮 = ρ液gV排
- **并且** 用户必须能够调节液体密度
- **并且** 用户必须能够调节物体浸入体积
- **并且** 系统必须实时计算并显示浮力大小
- **并且** 系统必须对比浮力和物体重力

#### 场景:潜水艇原理
- **当** 用户切换到应用模式
- **那么** 系统必须显示潜水艇模型
- **并且** 用户必须能够控制水舱充水或排水
- **并且** 充水时潜水艇必须下沉
- **并且** 排水时潜水艇必须上浮
- **并且** 系统必须标注浮力调节原理

### 需求:静态教学图
所有物理科学模拟页面必须提供静态SVG教学图。

#### 场景:声学静态图
- **当** 用户点击"静态展示"按钮
- **那么** 系统必须显示声波传播示意图
- **并且** 标注声源、介质、声波方向
- **并且** 对比不同音调、响度的波形
- **并且** 提供声音传播速度的参考表

#### 场景:光学静态图
- **当** 用户查看光学的静态图
- **那么** 系统必须显示光路图
- **并且** 标注入射角、反射角、折射角
- **并且** 展示反射定律和折射定律
- **并且** 提供生活应用案例（潜望镜、彩虹等）

#### 场景:电磁学静态图
- **当** 用户查看电磁学的静态图
- **那么** 系统必须显示电路图符号
- **并且** 标注电流方向和磁场方向
- **并且** 展示串联和并联的电路图
- **并且** 提供安全用电知识

#### 场景:浮力静态图
- **当** 用户查看浮力的静态图
- **那么** 系统必须显示浮力原理图解
- **并且** 标注受力分析图
- **并且** 展示阿基米德实验示意图
- **并且** 提供浮力应用案例（船、气球等）
