# 生命科学教育规范增量

## 新增需求

### 需求:生态系统可视化
系统必须提供食物链、生态系统等概念的可视化教学功能。

#### 场景:食物链展示
- **当** 用户打开食物链页面
- **那么** 系统必须显示完整的食物链示例
- **并且** 系统必须显示生产者（植物）、消费者（动物）、分解者（细菌真菌）
- **并且** 食物链必须使用从左到右或从下到上的箭头表示能量流动
- **并且** 用户必须能够点击每个生物查看其角色
- **并且** 系统必须标注"能量从生产者流向高级消费者"

#### 场景:食物网展示
- **当** 用户切换到食物网模式
- **那么** 系统必须显示复杂的食物网（多条食物链交织）
- **并且** 用户必须能够看到多个物种之间的捕食关系
- **并且** 系统必须使用不同颜色表示不同营养级
- **并且** 用户必须能够点击任意物种查看其食物来源和天敌
- **并且** 系统必须标注"食物网由多条食物链组成"

#### 场景:能量金字塔演示
- **当** 用户切换到能量金字塔模式
- **then** 系统必须显示金字塔形状的能量流动图
- **并且** 生产者必须位于最底层（能量最多）
- **并且** 初级消费者在第二层
- **并且** 次级消费者在第三层
- **并且** 顶级消费者在最顶层（能量最少）
- **并且** 每层必须标注能量传递效率（约10%-20%）

#### 场景:生态平衡模拟
- **当** 用户切换到模拟模式
- **那么** 系统必须提供一个简化的生态系统（如草地、兔子、狼）
- **并且** 用户必须能够调节各物种的数量
- **并且** 系统必须模拟种群数量的变化
- **并且** 某一物种过多或过少必须影响其他物种
- **并且** 系统必须展示生态平衡的重要性

#### 场景:分解者的作用
- **当** 用户点击分解者
- **那么** 系统必须显示分解过程动画
- **并且** 枯枝落叶和动物尸体必须被分解
- **并且** 分解产生的营养物质必须回到土壤
- **并且** 植物必须从土壤中吸收营养物质
- **并且** 系统必须标注"分解者促进物质循环"

### 需求:人体结构可视化
系统必须提供人体器官、系统的可视化教学功能。

#### 场景:人体器官概览
- **当** 用户打开人体器官页面
- **那么** 系统必须显示人体的3D模型
- **并且** 系统必须标注主要器官的位置：心脏、肺、肝、胃、脑、肾、肠
- **并且** 用户必须能够旋转模型观察器官位置
- **并且** 用户必须能够点击器官查看详细信息
- **并且** 系统必须使用不同颜色区分不同系统

#### 场景:循环系统演示
- **当** 用户点击心脏
- **那么** 系统必须放大显示心脏结构
- **并且** 系统必须显示四个腔室：左心房、左心室、右心房、右心室
- **并且** 系统必须使用红色表示动脉血，蓝色表示静脉血
- **并且** 系统必须显示血液流动路径
- **并且** 用户必须能够观看心脏跳动的动画

#### 场景:血液循环路径
- **当** 用户切换到血液循环模式
- **那么** 系统必须显示体循环和肺循环
- **并且** 血液必须从心脏流向全身再回到心脏（体循环）
- **并且** 血液必须从心脏流向肺部再回到心脏（肺循环）
- **并且** 系统必须使用动画展示血液循环
- **并且** 系统必须标注"血液运输氧气和营养物质"

#### 场景:呼吸系统演示
- **当** 用户点击肺部
- **那么** 系统必须显示气管、支气管、肺泡
- **并且** 系统必须显示呼吸时肺的扩张和收缩
- **并且** 系统必须使用动画展示氧气进入血液
- **并且** 系统必须显示二氧化碳从血液进入肺泡
- **并且** 系统必须标注"肺是气体交换的场所"

#### 场景:消化系统演示
- **当** 用户点击消化系统
- **那么** 系统必须显示完整的消化道：口腔、食管、胃、小肠、大肠
- **并且** 系统必须显示食物在各器官的消化过程
- **并且** 用户必须能够观看食物通过消化道的动画
- **并且** 系统必须标注每个器官的功能
- **并且** 系统必须解释营养物质的吸收

#### 场景:神经系统演示
- **当** 用户点击大脑
- **那么** 系统必须显示大脑的主要区域
- **并且** 系统必须标注大脑、小脑、脑干
- **并且** 系统必须显示神经的分布
- **并且** 用户必须能够点击身体部位查看对应神经控制
- **并且** 系统必须解释神经传递信息的原理

#### 场景:器官健康知识
- **当** 用户切换到健康模式
- **那么** 系统必须提供各器官的健康知识
- **并且** 系统必须解释吸烟对肺的危害
- **并且** 系统必须解释高盐高脂对心脏的危害
- **并且** 系统必须提供保护器官的方法
- **并且** 系统必须鼓励健康的生活方式

### 需求:生物适应性与进化
系统必须提供动物适应性、自然选择等概念的可视化教学功能。

#### 场景:保护色演示
- **当** 用户打开动物的适应性页面
- **那么** 系统必须显示具有保护色的动物（如变色龙、竹节虫）
- **并且** 用户必须能够调节背景颜色
- **并且** 动物的体色必须根据背景变化
- **并且** 系统必须标注"保护色帮助动物躲避天敌"
- **并且** 用户必须能够体验寻找伪装动物的难度

#### 场景:拟态演示
- **当** 用户切换到拟态模式
- **那么** 系统必须显示拟态的例子（如枯叶蝶、尺蠖）
- **并且** 动物必须模仿环境中的物体（叶子、树枝）
- **并且** 用户必须能够点击查看真实物体和模仿动物的对比
- **并且** 系统必须标注"拟态是动物模仿环境的行为"
- **并且** 系统必须解释拟态与保护色的区别

#### 场景:警戒色演示
- **当** 用户切换到警戒色模式
- **那么** 系统必须显示具有鲜艳警戒色的动物（如毒蛙、黄蜂）
- **并且** 警戒色必须使用鲜艳的颜色（红、黄、橙、黑）
- **并且** 系统必须标注"鲜艳的颜色警告天敌：我有毒"
- **并且** 系统必须对比警戒色和保护色
- **并且** 系统必须解释警戒色的作用

#### 场景:对环境的适应
- **当** 用户切换到环境适应模式
- **那么** 系统必须展示不同环境中的动物适应特征
- **并且** 沙漠动物必须展示节水适应（如骆驼的驼峰）
- **并且** 极地动物必须展示保暖适应（如北极狐的厚毛）
- **并且** 水生动物必须展示游泳适应（如鸭子的蹼）
- **并且** 用户必须能够选择不同环境查看适应特征

#### 场景:自然选择演示
- **当** 用户切换到自然选择模式
- **那么** 系统必须提供一个简化的进化模拟
- **并且** 环境必须发生某种变化（如颜色变化）
- **并且** 某些个体必须更有利于生存
- **并且** 有利特征的个体必须生存并繁殖
- **并且** 系统必须展示种群特征的逐渐变化

#### 场景:人工选择演示
- **当** 用户切换到人工选择模式
- **那么** 系统必须展示人工选择的例子（如农作物的育种）
- **并且** 系统必须对比野生种和栽培种
- **并且** 用户必须能够选择保留哪些特征
- **并且** 系统必须标注"人类选择需要的特征"
- **并且** 系统必须对比自然选择和人工选择

### 需求:植物与环境
系统必须提供植物对环境适应性的可视化教学功能。

#### 场景:植物对阳光的适应
- **当** 用户观察植物对阳光的适应
- **那么** 系统必须显示植物的向光性
- **并且** 植物必须向光源方向生长
- **并且** 系统必须标注"植物需要阳光进行光合作用"
- **并且** 用户必须能够调节光源方向
- **并且** 植物生长方向必须随之改变

#### 场景:植物对水分的适应
- **当** 用户观察植物对水分的适应
- **那么** 系统必须对比不同环境中的植物根系
- **并且** 干旱环境植物的根必须深且广
- **并且** 水生植物的根必须短小或不发达
- **并且** 系统必须标注"根吸收土壤中的水分"
- **并且** 系统必须解释仙人掌的储水适应

### 需求:静态教学图
所有生命科学教育页面必须提供静态SVG教学图。

#### 场景:生态系统静态图
- **当** 用户点击"静态展示"按钮
- **then** 系统必须显示食物链和食物网示意图
- **并且** 标注生产者、消费者、分解者
- **并且** 展示能量流动的方向
- **并且** 提供生态系统的填空练习

#### 场景:人体器官静态图
- **当** 用户查看人体器官的静态图
- **那么** 系统必须显示人体器官位置图
- **并且** 标注各器官的主要功能
- **并且** 展示各系统的组成
- **并且** 提供健康生活方式建议

#### 场景:生物适应性静态图
- **当** 用户查看生物适应性的静态图
- **then** 系统必须显示保护色、拟态、警戒色的对比图
- **并且** 标注每种适应性的作用
- **并且** 展示不同环境中的动物适应特征
- **并且** 提供动物分类参考表
