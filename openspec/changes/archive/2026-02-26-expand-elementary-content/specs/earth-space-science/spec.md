# 地球与空间科学规范增量

## 新增需求

### 需求:水循环可视化
系统必须提供水循环过程的可视化教学功能，帮助小学生理解自然界中水的运动。

#### 场景:水循环全过程展示
- **当** 用户打开水循环页面
- **那么** 系统必须显示包含海洋、陆地、山脉、天空的3D场景
- **并且** 系统必须显示水循环的四个主要过程：蒸发、凝结、降水、地表径流
- **并且** 用户必须能够点击播放按钮观看完整的水循环动画
- **并且** 动画必须使用蓝色粒子表示水分子运动
- **并且** 每个过程必须持续2-3秒

#### 场景:蒸发过程演示
- **当** 用户点击"蒸发"按钮
- **那么** 系统必须聚焦显示海洋或湖泊表面
- **并且** 水分子必须从水面向上升起
- **并且** 上升的水分子必须使用向上的箭头表示
- **并且** 系统必须标注"太阳加热使水蒸发成水蒸气"
- **并且** 用户必须能够调节温度观察蒸发速度变化

#### 场景:凝结过程演示
- **当** 水蒸气上升到高空
- **那么** 系统必须显示水蒸气遇冷凝结
- **并且** 水蒸气必须聚集形成云
- **并且** 云必须使用白色或灰色的蓬松形状
- **并且** 系统必须标注"水蒸气遇冷凝结成小水滴形成云"
- **并且** 用户必须能够观察云的形成过程

#### 场景:降水过程演示
- **当** 云中的水滴聚集到一定程度
- **那么** 系统必须显示降水过程
- **并且** 用户必须能够选择降水类型：雨、雪、冰雹
- **并且** 雨滴必须以倾斜角度下落
- **并且** 雪花必须缓慢飘落
- **并且** 系统必须标注"云中的水滴聚集后落下形成降水"

#### 场景:地表径流演示
- **当** 降水到达地面
- **那么** 系统必须显示水流沿着地表流动
- **并且** 部分水必须渗入地下成为地下水
- **并且** 部分水必须汇入河流最终回到海洋
- **并且** 系统必须标注"水通过地表和地下径流回到海洋"
- **并且** 系统必须展示完整的水循环路径

#### 场景:水循环交互探索
- **当** 用户切换到探索模式
- **那么** 用户必须能够点击场景中的任意元素查看详细说明
- **并且** 点击海洋必须显示"地球71%的表面被水覆盖"
- **并且** 点击云必须显示"云由无数小水滴或冰晶组成"
- **并且** 点击山脉必须显示"山脉是河流的发源地"
- **并且** 系统必须提供水循环的填空练习

### 需求:岩石与矿物可视化
系统必须提供岩石类型、矿物特性的可视化教学功能。

#### 场景:三大岩类展示
- **当** 用户打开岩石与矿物页面
- **那么** 系统必须显示三大岩类的3D模型：岩浆岩、沉积岩、变质岩
- **并且** 每种岩石必须显示真实纹理和颜色
- **并且** 用户必须能够点击岩石查看详细信息
- **并且** 用户必须能够旋转岩石观察不同角度
- **并且** 系统必须标注岩石的名称和形成环境

#### 场景:岩浆岩形成过程
- **当** 用户点击岩浆岩
- **那么** 系统必须显示岩浆冷却凝固的动画
- **并且** 用户必须能够选择侵入岩（缓慢冷却）或喷出岩（快速冷却）
- **并且** 侵入岩（如花岗岩）必须显示粗大的晶体
- **并且** 喷出岩（如玄武岩）必须显示细小的晶体
- **并且** 系统必须标注"岩浆冷却凝固形成岩浆岩"

#### 场景:沉积岩形成过程
- **当** 用户点击沉积岩
- **那么** 系统必须显示沉积物层层堆积的动画
- **并且** 沙、泥、砾石必须分层沉淀
- **并且** 上层压力必须使下层压实
- **并且** 系统必须显示明显的层理结构
- **并且** 系统必须标注"沉积物经压实、胶结形成沉积岩"

#### 场景:变质岩形成过程
- **当** 用户点击变质岩
- **那么** 系统必须显示岩石在高温高压下变化的动画
- **并且** 石灰岩必须变质成大理岩
- **并且** 页岩必须变质成片麻岩
- **并且** 系统必须展示岩石结构和矿物的重结晶
- **并且** 系统必须标注"岩石在高温高压下变质形成变质岩"

#### 场景:矿物特性观察
- **当** 用户切换到矿物模式
- **then** 系统必须提供多种矿物样本（石英、长石、云母等）
- **并且** 用户必须能够观察矿物的颜色、光泽、硬度
- **并且** 用户必须能够进行硬度测试（划痕测试）
- **并且** 系统必须标注矿物的化学成分和用途
- **并且** 系统必须提供矿物鉴定流程图

### 需求:地球结构可视化
系统必须提供地球内部结构的可视化教学功能。

#### 场景:地球内部圈层
- **当** 用户打开地球的结构页面
- **那么** 系统必须显示地球的3D剖面模型
- **并且** 系统必须标注三个圈层：地壳、地幔、地核
- **并且** 地壳必须使用最薄的一层（约5-70公里）
- **并且** 地幔必须使用最厚的一层（约2900公里）
- **并且** 地核必须分为内核和外核
- **并且** 各圈层必须使用不同颜色表示

#### 场景:地壳结构展示
- **当** 用户点击地壳
- **那么** 系统必须放大显示地壳的详细信息
- **并且** 系统必须显示地壳分为大陆地壳和海洋地壳
- **并且** 大陆地壳必须显示较厚（约35公里）
- **并且** 海洋地壳必须显示较薄（约5-10公里）
- **并且** 系统必须标注"地壳由岩石组成，是地球最外层"

#### 场景:地幔结构展示
- **当** 用户点击地幔
- **那么** 系统必须显示地幔的温度和状态变化
- **并且** 上地幔必须显示较硬
- **并且** 下地幔必须显示较软且温度更高
- **并且** 系统必须标注地幔的厚度（约2900公里）
- **并且** 系统必须解释地幔对流对板块运动的影响

#### 场景:地核结构展示
- **当** 用户点击地核
- **那么** 系统必须显示地核分为内核和外核
- **并且** 外核必须显示为液态（熔融的铁和镍）
- **并且** 内核必须显示为固态（极高压力下）
- **并且** 系统必须标注地核的温度（可达6000°C）
- **并且** 系统必须解释地核产生地球磁场

#### 场景:板块运动演示
- **当** 用户切换到板块模式
- **那么** 系统必须显示地球表面的板块分布
- **并且** 用户必须能够观察板块的运动方向
- **并且** 系统必须标注板块边界类型：生长边界、消亡边界、转换边界
- **并且** 用户必须能够点击边界查看地质现象（火山、地震、山脉）
- **并且** 系统必须解释板块运动的驱动力

### 需求:天气与气候可视化
系统必须提供气温、降水、风向等天气要素的可视化教学功能。

#### 场景:天气要素展示
- **当** 用户打开天气与气候页面
- **then** 系统必须显示天气预报的场景
- **并且** 系统必须显示四个主要天气要素：气温、降水、风向、湿度
- **并且** 用户必须能够调节每个要素的数值
- **and** 系统必须实时更新场景显示
- **并且** 系统必须显示对应的天气符号（晴、阴、雨、雪等）

#### 场景:气温变化可视化
- **当** 用户调节气温滑块
- **那么** 场景中的天空颜色必须随之变化
- **并且** 高温时天空必须显示为明亮的蓝色
- **并且** 低温时天空必须显示为灰蓝色
- **并且** 系统必须显示温度计读数
- **并且** 系统必须解释气温的日变化和年变化

#### 场景:降水类型演示
- **当** 用户选择降水类型
- **那么** 系统必须显示对应的降水动画
- **并且** 雨必须以水滴形式下落
- **并且** 雪必须以雪花形式飘落
- **并且** 冰雹必须以冰粒形式弹跳
- **并且** 系统必须标注降水的形成条件

#### 场景:风向与风力
- **当** 用户调节风向和风力
- **那么** 系统必须显示风向标旋转
- **并且** 系统必须显示树木和旗帜随风摆动
- **并且** 风力越大摆动幅度必须越大
- **并且** 系统必须使用箭头标注风向
- **并且** 系统必须解释风的成因（空气流动）

#### 场景:天气预报制作
- **当** 用户切换到预报模式
- **then** 系统必须提供简单的天气预报工具
- **并且** 用户必须能够观察气象卫星云图
- **并且** 用户必须能够根据云图预测天气
- **并且** 系统必须提供天气符号库
- **并且** 用户必须能够制作自己的天气预报图

#### 场景:气候与天气的区别
- **当** 用户切换到气候模式
- **那么** 系统必须对比天气和气候
- **并且** 天气必须显示为短时间的变化
- **并且** 气候必须显示为长期的平均状态
- **并且** 系统必须标注"天气是短期现象，气候是长期规律"
- **并且** 系统必须展示世界气候类型分布图

#### 场景:极端天气现象
- **当** 用户切换到极端天气模式
- **那么** 系统必须展示台风、龙卷风、暴雨等极端天气
- **并且** 用户必须能够观察台风的形成过程
- **并且** 系统必须标注台风眼和风力分布
- **并且** 系统必须提供极端天气的安全知识
- **并且** 系统必须解释气候变化对极端天气的影响

### 需求:静态教学图
所有地球与空间科学页面必须提供静态SVG教学图。

#### 场景:水循环静态图
- **当** 用户点击"静态展示"按钮
- **那么** 系统必须显示水循环示意图
- **并且** 标注蒸发、凝结、降水、径流四个过程
- **并且** 提供水循环的填空练习
- **并且** 展示水在自然界中的分布比例

#### 场景:岩石静态图
- **当** 用户查看岩石的静态图
- **那么** 系统必须显示三大岩类的对比表
- **并且** 标注每种岩石的代表矿物和结构特征
- **并且** 展示岩石循环示意图
- **并且** 提供常见岩石的识别指南

#### 场景:地球结构静态图
- **当** 用户查看地球结构的静态图
- **那么** 系统必须显示地球圈层结构图
- **并且** 标注各圈层的厚度和特性
- **并且** 展示板块分布图
- **并且** 提供地球内部数据参考表

#### 场景:天气静态图
- **当** 用户查看天气的静态图
- **那么** 系统必须显示天气符号库
- **并且** 标注各天气要素的测量方法
- **并且** 展示世界气候类型分布图
- **并且** 提供天气观测记录表
