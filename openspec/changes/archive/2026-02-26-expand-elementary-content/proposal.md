# 扩展小学教学内容提案

## 为什么

当前AetherViz应用仅包含12个教学页面，覆盖的小学数学和科学知识点有限。小学1-6年级有大量核心知识点尚未涉及，无法满足不同年级学生的多样化学习需求。通过扩展教学内容，可以覆盖更多小学课程标准要求的知识点，提供更完整的学习资源。

## 变更内容

### 新增功能

**数学模块（15个新页面）**：

1. **数线与数轴** - 1-2年级，数线跳跃计数、加减法可视化
2. **认识圆形** - 1-2年级，圆心、半径、直径概念
3. **分类与统计** - 1-2年级，颜色、形状分类统计
4. **乘法概念** - 3-4年级，分组、数组可视化
5. **除法概念** - 3-4年级，平均分、余数概念
6. **面积计算** - 3-4年级，正方形、长方形面积
7. **角度认识** - 3-4年级，锐角、直角、钝角识别
8. **对称图形** - 3-4年级，轴对称、中心对称
9. **认识长方体** - 5-6年级，顶点、棱、面
10. **认识圆柱体** - 5-6年级，展开图、侧面、底面
11. **认识圆锥体** - 5-6年级，母线、底面、高
12. **体积计算** - 5-6年级，柱体、锥体体积公式
13. **百分数** - 5-6年级，百分数与小数、分数互化
14. **比例与比例尺** - 5-6年级，实际距离与图上距离
15. **数据与概率** - 5-6年级，折线统计图、概率概念

**科学模块（12个新页面）**：

16. **声音的传播** - 3-5年级，声波、振动、音调可视化
17. **光的传播** - 3-5年级，直线传播、反射、折射
18. **电路基础** - 4-6年级，简单电路、串联并联
19. **磁铁的磁性** - 3-5年级，南北极、磁场线
20. **浮力原理** - 5-6年级，阿基米德原理、密度
21. **水循环** - 3-5年级，蒸发、凝结、降水过程
22. **岩石与矿物** - 4-6年级，岩石类型、矿物特性
23. **地球的结构** - 5-6年级，地壳、地幔、地核
24. **天气与气候** - 3-5年级，气温、降水、风向
25. **食物链** - 4-6年级，生产者、消费者、分解者
26. **人体器官** - 3-6年级，心脏、肺、消化系统
27. **动物的适应性** - 3-6年级，保护色、拟态

**技术特性**：
- 所有页面保持与现有页面一致的儿童友好设计
- 3D可视化 + 静态教学图双模式
- 响应式设计（手机/平板/桌面）
- 完整无障碍支持（WCAG 2.1 AA）
- 可选的问答系统和探索任务集成

### 修改功能

无。此变更仅添加新内容，不修改现有功能规范。

## 功能 (Capabilities)

### 新增功能

- **advanced-math-visualization**: 高级数学可视化（立体几何、代数概念、数据分析）
- **physical-science-simulation**: 物理科学模拟（声学、光学、电磁学、力学）
- **earth-space-science**: 地球与空间科学（地球结构、水循环、天气气候）
- **life-science-education**: 生命科学教育（生态系统、人体器官、生物适应性）

### 修改功能

无。现有的四个规范（kid-friendly-interface、elementary-math-visualization、elementary-science-simulation、interactive-learning-games）保持不变，新页面将遵循这些规范的现有要求。

## 影响

### 新增文件
- 27个新的HTML教学页面文件（`templates/lesson-*.html`）
- 4个新的规范文件（`openspec/specs/*/spec.md`）
- 27个SVG静态教学图
- 可选：新增题库和探索任务

### 修改文件
- `index.html` - 添加27个新课程卡片
- `PROJECT_STATUS_REPORT.md` - 更新统计数据

### 依赖项
- 无新依赖，继续使用Three.js r134、Tailwind CSS、Web Speech API

### 技术债务
- 需要保持代码一致性
- 确保所有新页面通过无障碍测试
- 需要确保在不同设备上的性能
