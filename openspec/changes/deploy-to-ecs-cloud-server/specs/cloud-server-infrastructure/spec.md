# 云服务器基础设施规范

## 新增需求

### 需求:ECS 服务器采购
系统必须采购符合规格要求的阿里云 ECS 实例。

#### 场景:购买 ECS 实例
- **当** 用户在阿里云控制台购买 ECS
- **那么** 系统必须提供以下配置：
  - 实例规格：ecs.t6-c1m2.large（2核4GB）
  - 操作系统：Ubuntu 22.04 LTS 64位
  - 系统盘：40GB ESSD Entry
  - 带宽：5Mbps（按使用付费）

#### 场景:成本验证
- **当** ECS 实例正常运行
- **那么** 月度成本必须在 ¥70-90 之间
- **并且** 按量付费模式必须生效

### 需求:安全组配置
系统必须配置安全组规则以允许必要的网络流量。

#### 场景:配置入方向规则
- **当** 用户配置安全组
- **那么** 系统必须开放以下端口：
  - 22/TCP（SSH）：0.0.0.0/0
  - 80/TCP（HTTP）：0.0.0.0/0
  - 443/TCP（HTTPS）：0.0.0.0/0
- **并且** 拒绝所有其他入方向流量

#### 场景:限制 SSH 访问
- **当** 用户希望提高安全性
- **那么** 可以将 22 端口的授权对象限制为特定 IP

### 需求:系统初始化
服务器必须安装和配置必要的软件环境。

#### 场景:安装基础软件
- **当** 用户首次 SSH 登录服务器
- **那么** 系统必须安装以下软件：
  - Nginx（Web 服务器）
  - Git（版本控制）
  - Node.js 和 npm（运行时环境）
  - UFW（防火墙）
- **并且** 更新系统到最新版本

#### 场景:配置防火墙
- **当** UFW 防火墙启用
- **那么** 必须允许以下端口：
  - 22（SSH）
  - 80（HTTP）
  - 443（HTTPS）
- **并且** 拒绝所有其他入方向连接

### 需求:目录结构
系统必须创建规范的目录结构以支持多项目部署。

#### 场景:创建项目目录
- **当** 初始化服务器
- **那么** 系统必须创建以下目录：
  - `/var/www/`（项目根目录）
  - `/var/www/shared/ssl/`（SSL 证书）
  - `/var/www/shared/logs/`（日志）
  - `/var/www/shared/backups/`（备份）
  - `/var/www/math-education/`（数学教育项目）
- **并且** 设置正确的权限（755）

#### 场景:设置目录权限
- **当** 目录创建完成
- **那么** 所有者必须设置为 www-data:www-data
- **并且** 权限必须设置为 755

### 需求:Nginx 基础配置
系统必须安装并配置 Nginx 作为 Web 服务器。

#### 场景:启动 Nginx 服务
- **当** Nginx 安装完成
- **那么** 系统必须启动 Nginx 服务
- **并且** 设置为开机自启（systemctl enable）
- **并且** 验证服务状态（systemctl status）

#### 场景:测试默认页面
- **当** 用户访问服务器公网 IP 的 80 端口
- **那么** 系统必须显示 Nginx 默认欢迎页面
